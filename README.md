## 🌟 Overview

**LifeMap Student** is a student motivational and living journey platform built from scratch with pure web technologies (**HTML5**, **CSS3**, **Vanilla JavaScript**, **SVG**, **Web Audio API**, and **LocalStorage**). 

Instead of displaying student goals as flat checklists or isolated notes, LifeMap represents your educational life as an **interactive living constellation**. Connecting curved paths show how foundational study habits lead directly to exam breakthroughs, hackathon victories, and all-time personal records.

---

## 🎯 Key Modules

1. **Study & Focus Zone (Pomodoro Timer)**:
   - 25m Focus / 5m Short Break / 15m Long Break intervals.
   - Subject-tagged sessions (*Algorithms*, *Calculus*, *Physics*, *Web Dev*).
   - Built-in procedural ambient study soundscapes (**40Hz Focus Wave**, **Library Rain**, **Deep Zen**) synthesized using the Web Audio API without external audio files.
2. **Courses & Target Grade Tracker**:
   - Course manager tracking credit weights, estimated scores, and target grades (*A+*, *A*).
   - Attendance monitor with safety shortage warnings.
   - Live exam countdown tickers.
3. **Student Health & Wellness Studio**:
   - 8-glass daily hydration tracker.
   - Sleep hours and brain recovery logger.
   - Energy mindset selector with actionable study tips.
   - Physical workout logger.
   - 2-Minute Box Breathing De-Stress guided exercise.
4. **Hall of Records & Personal Bests**:
   - All-time student records (*Highest GPA*, *Coding milestones*, *Endurance runs*, *Study streaks*).
   - Achievement badge unlock system (*Dean's List*, *Focus Master*, *Hackathon Warrior*).
5. **Interactive Student Constellation Map**:
   - SVG vector engine with matrix pan and zoom.
   - Draggable nodes with persistent coordinates.
   - Curved Bezier relationship paths.
   - One-click PNG snapshot export.
6. **Motivation Wall & Daily Spark**:
   - Curated high-performance affirmations with shuffle functionality.

---

## 🛠️ Technologies Used

- **HTML5**: Semantic layout, accessible modal dialogues, and form structures.
- **CSS3**: Modern custom property design tokens (CSS variables), glassmorphism, responsive breakpoints, glowing SVG filters, and print stylesheets.
- **Vanilla JavaScript (ES6+)**: Zero framework dependencies (no React, Vue, Node.js backend required).
- **SVG**: Scalable vector canvas engine for interactive constellation mapping and pure SVG analytics charts.
- **Web Audio API**: Client-side procedural audio synthesis.
- **LocalStorage**: 100% private client-side persistence.

## 🚀 How to Run Locally

### Option 1: Direct File Launch
Double-click `index.html` in your file explorer to open it directly in Chrome, Edge, Firefox, or Safari.

### Option 2: Local Python Server
```bash
python -m http.server 8080
```
Then visit: [http://localhost:8080](http://localhost:8080)

### Option 3: VS Code Live Server
Right-click `index.html` in Visual Studio Code and choose **"Open with Live Server"**.
